# 验收与恢复

| 操作 | 应核验的结果 | 常见误判 |
|---|---|---|
| 包覆纤维 | 连续表面、自然节点、保留孔隙，放大图同步 | 仅增加细丝数量或套一个不相连圆柱 |
| 删穿模颗粒 | 候选数、可见吞入程度、正常贴附仍存在 | 全部几何接触都算错误 |
| 高清渲染 | 文件可解码、尺寸正确、透明度正确、光照一致 | 仅把低清预览放大 |
| 原位替换 | 父组、剪切、顺序、矩阵、混合模式一致 | 使用相同包围盒但旋转/裁切不同 |
| 文案编辑 | 内容正确，公式与抗体数字仍有正确下标 | 全文统一替换导致样式丢失 |
| 裁切背景 | 新画板底边、边框完整、其他叶节点位置不变 | 只开 Trim View 或缩放整图 |
| 软件展示 | 正确文档在前台，实际画面可见 | API 返回成功就声称用户已看到 |

## 恢复顺序

1. 脚本报错时读取日志，区分“预检失败、尚未写入”和“已部分修改”。
2. 比较当前文档与备份时间。用户在任务执行期间可能修改宽度、文字、背景或撤销上轮操作。
3. 优先针对实际部分修改修复；只有确认备份之后没有需要保留的用户编辑时，才恢复备份。不要自动反复 Undo。
4. 重读对象清单和坐标，生成本轮修改计划，再继续。

## 发布这类 Skill

只发布通用说明、通用脚本、合成测试资产及不含个人路径的样例配置。论文数据、原始截图、`.ai`、`.blend`、渲染成品和聊天日志需要另行明确授权。完成后报告真实仓库 URL、作者署名、Skill 名称和验证结果；权限失败不能说“已发布”。
